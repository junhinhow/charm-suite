## Quick Start / Começando Rápido

```bash
# Pick any library / Escolha qualquer biblioteca
go get github.com/junhinhow/charm-wizard
go get github.com/junhinhow/charm-themes
go get github.com/junhinhow/charm-test
```

Each repo has its own `README.md` with a minimal working example. / Cada repo tem seu próprio `README.md` com um exemplo mínimo funcional.

Para desenvolver localmente todos os 18 repos juntos, use o workspace:

```bash
git clone https://github.com/junhinhow/charm-suite
cd charm-suite
./scripts/bootstrap.sh      # Linux / macOS / WSL
# ou: .\scripts\bootstrap.ps1   (Windows PowerShell)
go work sync
```

Veja `scripts/README.md` para detalhes.

## Why this suite? / Por que esta suite?

**PT:** O stack oficial Charmbracelet é excelente, mas deixa lacunas: não há wizard pronto, nem sistema de temas unificado, nem framework de testes dedicado, nem DevTools, nem i18n, nem layout responsivo. A Charm Suite preenche cada uma dessas lacunas com bibliotecas pequenas, focadas e interoperáveis - todas escritas em Go idiomático e estilizadas com lipgloss.

**EN:** The official Charmbracelet stack is excellent but leaves gaps: no ready-made wizard, no unified theming, no dedicated test framework, no DevTools, no i18n, no responsive layout. The Charm Suite fills each of those gaps with small, focused, interoperable libraries - all idiomatic Go, all styled with lipgloss.

## Development / Desenvolvimento

- Cada repo é um **módulo Go independente**. A CI unificada de cada um está em `.github/workflows/ci.yml` e usa `go-version-file: go.mod` (a versão testada é sempre a real).
- Os 18 repos compartilham um **template de CI** e um **template de README** (veja `scripts/`).
- Commits seguem [Conventional Commits](https://www.conventionalcommits.org/) em português do Brasil.
- Issues e PRs são bem-vindos em qualquer `charm-*` repo. Mantenha mudanças pequenas, idiomáticas e cobertas por testes.
